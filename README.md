# Unsupervised_Model
Implementation of K-Means and Hierarchical Clustering, PCA-based dimensionality reduction, and Logistic Regression model evaluation using Scikit-learn. Includes Silhouette Score, confusion matrix, precision, recall, F1-score, ROC-AUC, 5-fold cross-validation, and GridSearchCV hyperparameter tuning.
#  Unsupervised Learning & Model Evaluation

This project explores unsupervised machine learning and model evaluation using Python and Scikit-learn.

### Project Contents
- K-Means Clustering on the Iris dataset
- Hierarchical Clustering
- Silhouette Score comparison
- Principal Component Analysis (PCA)
- Logistic Regression on the Breast Cancer dataset
- Confusion Matrix and ROC Curve
- Accuracy, Precision, Recall, F1-score and ROC-AUC
- 5-Fold Cross-Validation
- Hyperparameter tuning using GridSearchCV
- Original vs Tuned Model Comparison

### Key Results
- K-Means Silhouette Score: 0.4607
- Hierarchical Clustering Silhouette Score: 0.4498
- PCA variance retained: 95.85%
- Original Logistic Regression Accuracy: 96.49%
- Tuned Logistic Regression Accuracy: 97.37%
- Tuned Model Recall: 95.24%
- Tuned Model F1-score: 96.39%

### Technologies Used
Python, Google Colab, Pandas, NumPy, Matplotlib and Scikit-learn.

### Purpose
The purpose of this project is to understand clustering, dimensionality reduction, classification evaluation, cross-validation and hyperparameter optimization through practical implementation.
